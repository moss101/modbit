# PX-141 retained mutation check (2026-10-24)

Each mutation changes one source file by exact string replacement (refused unless the target text occurs exactly once), rebuilds the
desktop bundle, runs `apps/desktop/e2e/zdl-tokens.spec.ts` against the real Electron app and a real Core, and restores the file.
The gate must fail on every one. The token comparison is exact (one canonicalising function reads ZCode's capture and Modbit's
build). A first attempt applied two of these with `sed '0,/re/'`, which macOS sed silently ignores; they "passed" because they never
applied, which is why the replacement now fails loudly.
