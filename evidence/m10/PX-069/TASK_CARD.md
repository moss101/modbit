## Defects found on the real Mac and fixed here
1. **Wrong window at session start (macOS 27).** AppKit gives an application with a text view an untitled, on-screen Siri panel (`AXDialog`) in front of its real window. `computer.start` chose the window from `ListApplications`, the window server's list, which has no focus state and lists front-most first, so the session opened on the panel. `start_checks` now resolves the matched process (`ResolveApplication`, accessibility-backed focus and main state) and chooses from that. It fails closed if the identity changed. Regression test: `runtime::tests::a_session_starts_on_the_focused_window_not_the_front_most_one` (mutation B killed). This was the wrong window of the right, verified process: no identity boundary was crossed.
2. **A sheet could never be answered.** A window carrying a sheet is modal. The Core refused every input to a modal window, including the sheet's own buttons, while the helper allows inputs inside the sheet. The Core now exempts exactly elements inside a sheet (`Plan.in_sheet`); the rest of the blocked window is still MODAL_BLOCKING. Regression test: `runtime::tests::a_sheet_is_answered_and_the_window_it_blocks_is_refused` (mutation C killed), and the real-helper document/dialog test.

## Test defects found on the real Mac (the helper's real-permission tests had never run with permissions)
- `stop_halts_…` and `the_core_going_away_…` spawned the input and then waited with a blocking sleep on a one-thread runtime, so the input was never sent. They now use the multi-threaded runtime.
- The nudge test compared a fractional pointer position with a warp that lands on whole pixels, and asserted the earlier V01 measurement that another process's HID-tap posts do not move the hardware idle counter. On macOS 27 they do (re-measured: 2.13 s → 0.07 s). CUC-D04 requires only that the helper's **own** events never count as a person. The test now asserts that, and asserts that the helper agrees with the counter it measures for other processes' events. Renamed `the_helpers_own_events_are_never_a_person_and_anothers_count_as_the_hardware_counter_says`.
