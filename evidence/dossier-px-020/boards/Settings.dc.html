How much the agent may do without asking. The mode is set per task in the composer; this is the default for new tasks.

AskEvery protected effect asks you first, and rules are ignored.
SupervisedReading, editing, builds and tests run on their own. A protected effect asks unless a rule you made covers it.

Supervised with sandboxAlso runs without asking whatever is fully contained in a sandbox.
AutonomousRuns the routine work of a coding task on its own: builds, tests, project tools and installs.
