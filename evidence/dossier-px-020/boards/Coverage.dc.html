What Claude desktop and Devin ship, and where Modbit stands

Claude desktop 4.23118.1, Devin 3.12.43 and Cursor 3.25.6 are installed here. Their columns come from public documentation and release notes read on 2026-11-11 (Claude Code desktop docs, Devin release notes to 2026-11-09, Cursor 3.23 teardown), not from the app bundles. The Modbit columns come from tracing each feature through the protocol, the Core, the desktop bridge and the renderer on 2026-11-11.

The Core is ahead

Almost every row below is already in the protocol: checkpoints, worktrees, automations, skills, knowledge, forge comments, computer use, queue and steer, evidence, budgets.

The UI is behind

Where the Core says Yes and the UI says Part or a dash, the work is design and wiring: the pane dock, the activity pane, the plan’s steps, project rules, the hover preview, split view and cloud tasks from the desktop.

A few gaps are in the Core too

Next-prompt suggestion, pull-request state with auto-fix and merge, a persisted inbox and per-app computer access have no Core support yet. Side chat already works.
