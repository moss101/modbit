## Goal

One Protobuf schema source produces Rust and TypeScript bindings, and round-trip compatibility tests prove both sides encode and decode the same messages byte-for-byte in both directions.

## Non-goals

- Transport, framing, authentication, command dispatch (M1.3).
- The full event catalogue of docs/30 (added with M1.1 event store); M0.3 ships the envelopes, tool call wire schema, OutputRef reads and version negotiation.

## Invariants

- `proto/` is the only schema authority; never reuse or renumber a field; additive inside a major.
- Rust bindings generated at build time by a pure-Rust compiler (no system protoc); TS bindings generated by `pnpm generate` and committed; CI fails on drift.
- 64-bit integers, bytes, optional presence, enums and repeated fields round-trip byte-identically.
